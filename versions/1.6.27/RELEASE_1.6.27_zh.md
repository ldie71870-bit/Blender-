# 1.6.27：自动路径进度文件锁定修复

修复自动生成路径可能报错并中止：

```text
[WinError 5] 拒绝访问：...\\progress.tmp -> ...\\progress.json
```

自动路径在独立 Blender 后台进程中生成，前台界面同时读取
`progress.json` 显示进度。在 Windows 上，病毒防护、索引服务或前台读取
可能短暂锁定此文件。旧版将进度更新视为必需操作，替换文件失败便会中止
整条排线路径。

本版为每次进度更新使用独立临时文件，并对共享冲突进行短间隔重试。进度
文件仍无法写入时只跳过该次显示更新，后续回调会继续尝试，路径计算、预览
导入与结果文件不会受影响。`result.json` 保持严格写入，因此真正的后台
生成失败仍会正常报告。

## 验证

- Blender 5.0：注入三次 `PermissionError(WinError 5)` 后进度写入自动恢复。
- Blender 5.0：持续锁定时，可选进度写入返回失败而不终止任务；必需结果
  文件仍正确抛出错误。
- Blender 5.0：真实后台自动路径生成、结果导入、ESC 取消、失败清理和损坏
  进度文件回归通过。
