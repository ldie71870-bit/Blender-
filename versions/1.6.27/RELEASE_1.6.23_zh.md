# 1.6.23：安装与重载注册冲突修复

修复安装/启用插件时出现 `already registered as a subclass 'GS_OT_heat_job'` 的错误。

旧版卸载在覆盖缓存或绘制句柄清理时异常，会跳过之后的类注销。新版按 Blender 实际 RNA 标识找回旧类，逐项清理，避免新旧 Python 类身份不同导致漏卸载。缓存清理失败不再阻断其他清理；注册中途失败会回滚，以便重新安装。

重复启用、禁用和主模块重载会清理本插件的旧回调、快捷键和绘制句柄。场景参数、路径和相机保留。本版本包含 1.6.22 自动路径进度兼容修复；排线、覆盖和补拍算法保持原样，核心优化另行继续。

## Blender 5.1.1 验证

- 仅残留旧覆盖操作类时成功恢复安装。
- 连续注册三次，类和覆盖回调均不重复，用户参数保留。
- 注入缓存清理错误后仍完成全部类清理；连续卸载不报错。
- 子模块重载造成新旧类身份不同后，仍能重新注册。
- 注册中途注入故障能回滚，恢复后可再次启用。
- 1.6.22 自动路径 modal 测试通过：真实后台生成并导入 27 条曲线，异常进度、取消和失败清理正常。
