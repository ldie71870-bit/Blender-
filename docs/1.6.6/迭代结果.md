# 1.6.6：可选 CAD 平面图站点配额

路径规划完成后，可开启“站点配额平面图”。插件会临时创建正交相机，使用 Workbench 渲染生成灰白 CAD 风格底图，随即恢复原相机、渲染器、输出分辨率、世界背景和对象渲染可见性，并将当前区域切换到独立图像编辑器。临时相机与数据会立即删除。

图像编辑器通过 GPU 叠加蓝色路径、青色常规站点、粉色区域配额站点、绿色矩形及数量标签。用户先输入目标站点数，再直接在图上拖框。图像缩放和平移使用 Image Editor 的 View2D 坐标反算，区域始终对应固定世界 XY 范围。

区域配额替换框内的常规采样，框外保留原分配；一个区域跨越多段路径时按各段长度分配。多个区域不能重叠。若完整细部短线位于低配额区域内，原有最低采样数继续作为安全下限，面板同时显示实际数和目标数。

功能默认关闭。关闭时区域配置不会进入 `active_station_regions`，路径采样与 1.6.5 保持一致。区域数据保存在 `.blend`，再次开启即可恢复。
