# 1.6.5：单路径轻量相机检查

新增零对象的视口检查模式。选中一条路径后，可在 N 面板点击“孤立所选路径并查看相机”，或按 `Alt + Shift + I`。模式会隐藏同一路径集合中的其他曲线和插件生成相机的原生线框，同时保留墙体、家具、楼板等完整场景。当前路径会临时置顶显示。

相机光心由青色 GPU 点表示，镜头本地 `-Z` 朝向由橙色短线表示。点大小、米制朝向线长度和穿透显示均可调。位置、朝向和 GPU 批次只在进入、刷新或参数改变时重建；静止观察时直接复用缓存。退出后恢复进入前每条路径、每台相机以及当前曲线的显示状态。

绿色金字塔 Mesh 代理功能已完整移除，包括属性、面板、操作器和球壳生成阶段。加载旧文件、生成相机或进入检查时会清理 `GS_CAMERA_MESH_STYLE` 残留对象、集合、共享 Mesh 和材质，并恢复真实相机原显示尺寸。

## 验证

- Blender 5.1.1 交互式视口 GPU 实绘通过，无绘制回调错误。
- Blender 后台状态测试通过：目标路径保留，其他路径隐藏，场景几何不受影响，原生相机隐藏，退出后精确恢复。
- 进入检查没有新增代理对象；测试中的旧 Mesh 代理被删除。
- 示例路径 11 台相机首次几何构建 4.094 ms，缓存读取 0.023 ms。
- Luna 球壳回归：252 个站点、2939 台相机、85 台逐台剔除、0 个整站跳过、0 个重复光心。
- 16 项轮廓、细部覆盖、低位空隙与跨层算法测试全部通过；轮廓 Blender 验收通过。
