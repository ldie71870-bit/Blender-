# 1.6.9 可编辑区域排线

## 已实现

- 默认关闭的“启用区域排线”开关，以及当前视图中心创建线框 Box、选中区域、编辑形状、封闭性检查入口。
- 使用 Blender 原生 Mesh，可移动、旋转、非均匀缩放，在编辑模式加线、移动顶点、挤出成为封闭异形。非三维视图入口使用 3D 游标位置。
- 使用实际封闭网格内部约束路径。主线、细部短线、门洞探入和相机审计补线共用约束。逐段检查每个边界交点之间的区间，防止凹形的两个内部端点之间穿出区域。
- 区域启用时采集框内各可行连通部分，不依赖框外旧游标。只缩减 XY 地面采样范围，仍检测真实场景中位于区域下方的支撑地面。
- 区域框为非渲染辅助物，不作为排线、球壳或科学相机的碰撞障碍，也不进入导出点云采样。约束对象是路径中心线，不是相机视野和球壳外沿。
- 沿用独立后台进程、快照、取消和生成预览流程。原场景对象保留，成功后切换当前路径预览。

## 验证

`luna/zz/Luna.blend` 保留区域中的 14 条原路径作为范围参考，创建删去左上角的 L 形体积。实际生成四层主线及门洞/表面审计补线：

| 项目 | 结果 |
| --- | ---: |
| 地面采样列 | 754 |
| 生成主线 | 4，每个高度层一条 |
| 通过实际相机收益筛选的补线 | 3 |
| 总路径 | 7 |
| 检查路径段 | 492 |
| 越出实际区域的路径段 | 0 |
| 原场景对象与 14 条保留曲线 | 全部保留 |
| 执行时间 | 约 84 秒 |

本轮实景验证关闭了旧版高密度细部表面遍历，保留门洞与实际相机审计。细部补线的区域约束另在合成 L 形房间中验证，不能将此次结果解释为重新验证了全场景高斯训练覆盖率。

合成 Blender 测试验证了默认关闭、旋转、负缩放、编辑模式加线、L 形凹角、开放网格报错、内部段保留、跨区域段拒绝、关闭区域后恢复原流程、真实地面/顶棚探测、科学相机 BVH 排除辅助框，以及后台快照/返回集合中的区域指针和每段路径。原多楼层轮廓回归、全局代理/孤立恢复、门洞遮挡和 16 项算法测试通过。

## 版号与安装

面板顶部显示 `GS UI v1.6.9`。旧代码在扩展加载器替换 `bl_info` 后可能退回默认 `1.3.4`，新版在模块加载时保存版本，清空元数据后仍显示正确版号。

隔离配置中的真实“从磁盘安装”还复现了注册期 `_RestrictData` 不允许访问场景对象的问题。新版将代理初始化推迟至注册结束后，通过 Blender 官方构建器打包，并完成真实安装、启用、区域创建、封闭性检查和集成面板绘制检查。未修改用户正在使用的 Blender 配置。

安装包：`blender_gs_colmap_exporter-1.6.9-region-box.zip`。

使用：N 面板 GS → 室内多层排线 → 轮廓排线 → 启用区域排线 → 创建区域框 → 编辑/缩放 → 在区域内生成路径。区域必须封闭且无自相交；暂不支持开放平面。已有相机不会因编辑区域自动删除或重建，需要在确认路径后生成相机。

实景副本为本地 `validation_1.6.9/zz_region_169_review.blend`，原 Luna 文件未覆盖，场景模型和截图不上传仓库。
